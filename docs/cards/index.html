08/31 15:40 기준 · 버튼 하나로 스레드에 공유

① 본문 (붙여넣기)

② 댓글 (게시 후 첫 댓글로)

상품별 링크 (하나만 공유할 때)

1. 에이팔란스 제트 쿨링 휴대용 냉각 손선풍기 K300…
2. 쉬블링로브 스포츠 힙색 BLZ0209, 블랙, FR…
3. 닥터오레고닌 오리밤 멀티스틱, 10g, 3개
4. 디펜턴 토탈 솔루션 플러스 앰플 세럼, 30ml, …

📱 순서: 맨 위 공유 버튼 → 스레드 선택 → 사진 첨부됨 → 본문 붙여넣기 → 게시. 게시 후 댓글 복사하기 → 그 글의 첫 댓글로 붙여넣기.
(스레드 본문은 링크가 4개까지라, 사이트 전체 링크는 댓글로 답니다.)
공유가 안 되는 기기면: 카드 이미지를 길게 눌러 저장 → 본문·댓글 복사 → 스레드에 올리기.
